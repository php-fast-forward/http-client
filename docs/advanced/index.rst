Advanced Topics
===============

These pages explain the parts of the package that are easy to overlook once you
move past the quick start:

- how the provider fits into a larger container composition;
- how the PSR-18 client depends on PSR-17 services from elsewhere;
- how to override the default Symfony transport or replace the PSR-18
  registration entirely.
